ELEMENTS / LAB — Interactive Periodic Table

Files:
- index.html: full website (HTML, CSS, JavaScript).

Run locally:
1. Open index.html in Chrome, Edge, or Firefox.
2. The 118-element table and core details work from built-in data.
3. If connected to the internet, the page attempts to load expanded scientific properties from an open JSON dataset.

Features:
- Responsive periodic table with all 118 elements
- Animated starfield/nebula background, hover effects, modal transitions
- Search by element name, symbol, or atomic number
- Filter by chemical family and physical state
- Detailed element profile with atomic properties, electron configuration, discovery and uses when available
- Random element and reset controls

Scientific note:
Some values are unavailable, isotope-dependent, predicted, or source-dependent. This is an educational reference and should not replace authoritative laboratory or safety references.
